Realtime chat application with Deno and React

2023-09-11

Deno ReactJS WebSocket
code_folder: view repository

In this post, we take a look at how to build a chat application using Deno as the tool for frontend and backend. We use the same setup with React as before, while the backend runs on vanilla Deno.

For the chat functionality, we use WebSockets and store the chat on the server for a historical log. To keep things simple, we skip login, validation, and sanitization of messages.

Shared types (part 1)

To make it easier down the line, we want shared interfaces between frontend and backend. Create a shared.ts file and add the following. 

export type Message = {
  from: string;
  body: string;
  timestamp: string;
};

Now that we have a shared interface ready, we can move on to the backend.
